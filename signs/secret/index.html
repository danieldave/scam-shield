Warning sign: Asks for PIN, password, OTP or codes

Quick answer: Codes like a PIN, OTP or password exist to prove it is you. An honest company already has what it needs and never asks you to send them.

Words our checker looks for

pin · otp · password · passcode · one-time · one time · cvv · bvn · nin · verification code · security code · login details · card details · card number · account number · login · bank card · card photo

Our checker is careful: it only counts these words when the same sentence is asking you for them. "No BVN required" is a promise, not a request.
